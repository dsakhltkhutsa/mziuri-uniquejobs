# 💼 Mziuri UniqueJobs

A modern **Flask Job Board** where users can find jobs, apply for positions, and manage their applications. Admins can manage job listings and review applications.

🌐 **Live Demo:** https://mziuri-uniquejobs.onrender.com/

---

## 🚀 Features

### 👤 User
- 🔐 Register & Login
- 🔒 Secure password hashing
- 💼 Browse job listings
- 📄 View job details
- 📨 Apply for jobs
- 📋 View personal applications
- ✏️ Edit profile

### 🛠️ Admin
- ➕ Add jobs
- ✏️ Edit jobs
- 🗑️ Delete jobs
- 👥 View users
- 📨 Manage applications
- ✅ Update application status

## ⚡ Installation

```bash
git clone https://github.com/dsakhltkhutsa/mziuri-uniquejobs.git

cd mziuri-uniquejobs

pip install -r requirements.txt

python app.py
```

Open your browser:

```
http://127.0.0.1:5000
```
